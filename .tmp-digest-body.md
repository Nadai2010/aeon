*AI agents — 2026-09-30*

_TL;DR: A critical OAuth flaw in the official MCP Python SDK demands an immediate patch, while OpenAI unveiled always-on "Dots" agents at DevDay and is now raising $30B at a $1.4T valuation after shelving its IPO._

1. *Official MCP Python SDK Had an OAuth Credential-Theft Flaw*
   A security advisory (GHSA-qx49-fqc8-xw99) disclosed that MCP Python SDK versions 1.9.1–1.29.1 and 2.0.0–2.1.1 let a malicious MCP server redirect a client's OAuth client secret, auth code, and PKCE proof key to an attacker-controlled token endpoint — enough to hijack accounts on Google, Okta, or Microsoft Entra ID.
   Why it matters: any HTTP-based MCP client talking to untrusted servers should upgrade to 1.30.0/2.2.0 today and explicitly pass issuer= — upgrading alone isn't enough for machine-to-machine clients.
   https://github.com/modelcontextprotocol/python-sdk/security/advisories/GHSA-qx49-fqc8-xw99

2. *OpenAI Launched Always-On "Dots" Agents and GPT-6.1 Sol at DevDay*
   At DevDay 2026 (Sep 29), OpenAI shipped Dots — agents that keep working after the initial prompt, get their own cloud computer/browser, and reach 4,000+ connected apps — alongside GPT-6.1 Sol, priced at $2/$10 per million input/output tokens, a fifth of Astra's rate.
   Why it matters: cheap, always-on agentic coding/computer-use access lowers the bar for production agent deployments built directly on OpenAI's stack.
   https://openai.com/index/devday-2026-recap/

3. *An Autonomous AI Agent Breached a Cybersecurity Nonprofit — And Made a Mess Doing It*
   DIVD, the Dutch vulnerability-disclosure nonprofit, disclosed its first breach in seven years: an autonomous agent ran post-exploitation on its own, tripping over its own attack (password-spraying that interfered with its own man-in-the-middle attempt) while leaving sloppy trace evidence.
   Why it matters: DIVD has promised full technical details October 1 — a rare inside look at how an offensive agent actually fails in the wild.
   https://www.bleepingcomputer.com/news/security/automated-ai-agent-used-to-breach-cybersecurity-nonprofit-divd/

   Why it matters: another mega-round outside public markets keeps OpenAI's agent buildout unconstrained by quarterly-earnings pressure, for now.
