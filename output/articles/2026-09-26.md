# GitHub's Most-Starred Agent Skills Repo Isn't Anthropic's — It's Not Even Close

Today's top pick on GitHub Trending is [mattpocock/skills](https://github.com/mattpocock/skills), a personal collection of Markdown instruction files that TypeScript educator Matt Pocock publishes "straight from my .agents directory." As of this morning it sits at **269,929 stars** — verified live via the GitHub API — against **178,472** for [anthropics/skills](https://github.com/anthropics/skills), the company's own reference implementation of the Agent Skills spec. Pocock's repo has more stars than Anthropic's despite being built in about seven and a half months against Anthropic's roughly one year.

And Pocock isn't even the biggest fish. [obra/superpowers](https://github.com/obra/superpowers), a prescriptive "agentic development methodology" built by Jesse Vincent, currently carries **291,805 stars**. A third community entry, [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) from former Google Chrome engineer Addy Osmani, adds another **99,164**. Add the three together and you get 660,898 stars sitting on independently maintained, non-official skill collections — roughly 3.7 times what the spec's own reference repo has accumulated.

## Three different bets on what a "skill" should be

The interesting part isn't just the star count, it's that these three repos disagree with each other about what an agent skill is for.

Pocock's collection is small and curated — around two dozen files covering recurring engineering tasks like interviewing a user about a vague request, writing a spec, or running test-driven development. His README frames the whole project in opposition to a specific failure mode: "My agent skills that I use every day to do real engineering — not vibe coding" ([mer.vin](https://mer.vin/news/mattpocock-skills-the-skill-pack-topping-github-trending/)). Vincent's superpowers repo goes the other direction: it's a full methodology, more prescriptive workflow engine than reference library. Osmani's collection leans toward "production-grade" guardrails and verification-first practices aimed at teams shipping real software, not solo tinkering.

None of these are forks of Anthropic's repo or of each other. They're three independent answers to the same question, and the market — measured crudely in stars — has rewarded all three of them more than it's rewarded the spec author.

## The dotfiles parallel

A recent [AgentConn analysis](https://agentconn.com/blog/agent-skills-new-dotfiles-repos-racing-250k-stars-2026/) put a name on the pattern: agent skills are becoming the new dotfiles. Personal dotfiles repos never converged on a standard either — everyone's `.vimrc` and shell config is popular in isolation, portable in theory, and incompatible in practice the moment you try to merge two people's setups. AgentConn's framing is blunt: "star velocity is measuring enthusiasm, not maturity," and the risk is that skills fragment the same way, with popularity signaling engagement rather than interoperability.

There's a real adoption number underneath the metaphor: `AGENTS.md`, the emerging cross-agent instruction-file convention, had already crossed 60,000 public repos by May 2026, well before this trending spike — so the standardization Anthropic's spec is nominally trying to anchor is being pulled in multiple directions by repos with more gravity than the spec itself.

## Why it matters

A spec's reference implementation is supposed to be the thing everyone else measures against. When three independently maintained alternatives outstrip it in adoption signal — one of them by more than 60% — the reference stops functioning as the center of gravity. What replaces it, on current evidence, isn't a single winner but a handful of competing philosophies (curated-minimal, prescriptive-methodology, production-guardrails) that happen to share a file format. Teams picking a skills setup today aren't adopting "the Anthropic standard" so much as choosing a camp, which is exactly the dynamic that kept dotfiles fragmented for a decade. Worth watching whether `AGENTS.md`-style convergence catches up before the ecosystem calcifies around three incompatible defaults instead of one.
